# stavya-para-paroktih

Topics browser for `data/topics-export-flat.json`.

## Run the UI

1. **With http-server**: from the project root run  
   `npm install` then `npm start`  
   (or `npx http-server -p 8080 -c-1`).  
   Open http://localhost:8080 and use the Topics Browser.

2. **With another static server**: e.g. `npx serve .` then open http://localhost:3000.

3. **Without a server**: open `index.html` in your browser and use **Load from file** to choose `data/topics-export-flat.json`.
